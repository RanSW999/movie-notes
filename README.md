
This is a movie-notes app. It happens quite often that despite having watched many movies, I can't choose to rewatch any good ones with my friends, or when I'm thinking of a specific plot point but I can't exactly remember how I felt about it, this web app can help me leave notes about each movie so it's perfectly organized and accessible. It has a wide variety of movies and saves any notes I leave about them.
